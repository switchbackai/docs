Switchbak captures your AI coding sessions, normalizes them into a unified format, audits each one, attributes them to the changeset they created. A **Receipt**, the distilled, cited record, is produced that describes why a change looks the way it does. It holds the intent, constraints, decisions, redirects, negatives, open questions, each changed path matched to its cited reason, along with other data.

1. [Get started](get-started.md): install the client, log in, connect GitHub, and get your first Receipt
2. [Guides](../guides/receipts.md): read the Receipt on a pull request, and run each command of the CLI
3. [Admin](../admin/invite-teammates.md): invite the members of your organization, and connect GitHub
4. [Security](../security/security-and-privacy.md): what the client sends, where each copy of a session is held, and what erase removes
5. [Resources](../resources/glossary.md): the glossary, the FAQ, and how to get help


Supported agents: Claude Code, Codex, Cursor, Gemini CLI, and OpenCode

Switchbak is in beta. The [FAQ](../resources/faq.md#what-are-the-terms-of-the-beta) names the terms.
