# switchbak

Each pull request gets a Receipt: the record of the sessions behind the
change. Switchbak carries those sessions from your Mac to the switchback
warehouse of your organisation.

## Install

    brew install switchbackai/tap/switchbak
    switchbak signup

[User guide](GUIDE.md): install, sign up, set up, connect GitHub, erase.

## Data

[Where your data goes](DATA-NOTICE.md): each place a session goes, what is
held there, and what erase removes.

## Source

The release workflow of the switchback repository writes `GUIDE.md` and
`DATA-NOTICE.md` here on each release. Do not edit them in this repository.
